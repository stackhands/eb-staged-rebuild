The stager makes a sealed staged directory owner-writable for one rewrite or rename, then puts its mode back. On some filesystems that mode change replaces an access list, and the list stayed replaced. The stager restores the list after the mode. It flushes the directory once that list is back. A parent directory is flushed only after its own list is back. A failed flush refuses the update. The stager refuses a seal whose directory name is empty, `.` or `..`.
