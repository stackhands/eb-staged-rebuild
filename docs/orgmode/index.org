* eb-staged-rebuild

eb-staged-rebuild rebuilds software that EasyBuild has installed already, without taking the installation away from the jobs that use it.
EasyBuild's =--rebuild= empties the installation directory before the new build has passed its checks, so for the length of the build the path holds a partial installation, or none.
eb-staged-rebuild has EasyBuild install into a separate tree instead, and once that tree is complete it exchanges the two directories and then replaces the module file.
On a filesystem that exchanges two directories in one call, such as ext4, the path names a complete installation throughout.
The previous tree stays on disk under a hidden name until its grace period is over, and a rollback brings it back.
Each run keeps a journal, so a build that failed or a machine that went down leaves a run to finish or to undo.
It can also record every publication in a signed eb-stack ledger.
The tool is a static Zig binary. A thin Python package carries it for =pip=, starts it for =python3 -m eb_staged_rebuild=, and adds the EasyBuild site hook file and a checksum list for a copied install.
