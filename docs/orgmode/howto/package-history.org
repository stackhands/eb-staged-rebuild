* Write the history of each package

Turn the ledger into one page per package, in Markdown and in JSON, that says which modules it has, where they are, and every change to them, with corrections applied.
=project= writes the pages only from a log that =eb-stack ledger verify= accepted against a signed head that covers every record.

** Before you start

- The eb-stack 0.7.0, the log, the head and the public key of [[file:record-in-a-ledger.org][Record each rebuild in a signed ledger]], and the private key to sign a current head.
- A directory for the pages, here =/opt/site/ledger-history=, that is missing or holds only what an earlier =project= wrote there.
- With the Python package, run =python3 -m eb_staged_rebuild.ledger_maintenance= where this guide runs =eb-staged-rebuild ledger-maintenance=.

** Steps

1. Write the pages:

   #+begin_src bash
   eb-staged-rebuild ledger-maintenance project --eb-stack /opt/site/bin/eb-stack --log /opt/site/ledger/stack.jsonl \
     --public-key /opt/site/keys/ledger.pub --head /opt/site/ledger-heads/head.json --out /opt/site/ledger-history
   #+end_src

   #+begin_example
   ledger-maintenance: head /opt/site/ledger-heads/head.json covers 5 of the 7 records in /opt/site/ledger/stack.jsonl; sign a current head before reading
   #+end_example

   =project= refuses, with exit status 2: the rollback of =example-4= signed this head, and the two records of =build-events= came after it.
   =build-events= signs its heads in its outbox, not here.
2. Sign a head that covers every record:

   #+begin_src bash
   /opt/site/bin/eb-stack ledger head --log /opt/site/ledger/stack.jsonl --key /opt/site/keys/ledger.pem \
     --out /opt/site/ledger-heads/head.json
   #+end_src

   #+begin_example
   signed head size 7 root ba6f1be48e4d5a551dda63607955c17cd5d3e4f22d8c9ff748d673d5630bfc63 at 2026-11-17T01:50:35Z to /opt/site/ledger-heads/head.json
   checkpoint eb-stack-ledger/2026.06/2026 size 7 root ba6f1be48e4d5a551dda63607955c17cd5d3e4f22d8c9ff748d673d5630bfc63 to /opt/site/ledger/stack.jsonl.tiles/checkpoint
   #+end_example

3. Write the pages again:

   #+begin_src bash
   eb-staged-rebuild ledger-maintenance project --eb-stack /opt/site/bin/eb-stack --log /opt/site/ledger/stack.jsonl \
     --public-key /opt/site/keys/ledger.pub --head /opt/site/ledger-heads/head.json --out /opt/site/ledger-history
   #+end_src

   #+begin_example
   {"files": ["index.json", "index.md", "packages/Example.json", "packages/Example.md"], "out": "/opt/site/ledger-history", "packages": 1, "root": "ba6f1be48e4d5a551dda63607955c17cd5d3e4f22d8c9ff748d673d5630bfc63", "size": 7}
   #+end_example

** If it fails

| Message                                                                                              | Cause                                            | What to do                                                                          |
|------------------------------------------------------------------------------------------------------+--------------------------------------------------+-------------------------------------------------------------------------------------|
| =ledger-maintenance: head HEAD covers N of the M records in LOG; sign a current head before reading= | Records were appended after the head was signed. | Sign a current head with =eb-stack ledger head=, as in step 2.                      |
| =ledger-maintenance: head HEAD covers M records but ledger LOG has N=                                | The log is shorter than the head says.           | Records were removed from the log; compare it with the anchors before you trust it. |
