* Finish a run that failed or stopped

Finish a rebuild whose build failed, or that stopped part way because the command was killed or the machine went down, without starting it over.
The run's journal in the state root records how far it got, and =resume= goes on from there.

** Before you start

- The run's name, and its state root: =/opt/site/.eb-staged-rebuild= for the site of [[file:rebuild.org][Rebuild an installed module]].
- No other command using the run: =resume= waits for the state root's lock, which a run, a rollback, =gc= or =retire= holds while it works.
- For a build that failed, what made it fail, from EasyBuild's output or log.

   A run that stopped part way shows the state it stopped in: =created= or =building= while the build ran, =built= or =publishing= once it had finished.
2. Correct what made the build fail.

   #+begin_src bash
   cp /home/alice/sources/example-1.0.sh /opt/site/sources/e/Example/example-1.0.sh
   #+end_src

   A run that stopped without an error needs nothing corrected.

** Check that it worked

The run is complete, and its module is published:

#+begin_src bash
eb-staged-rebuild status --state-root /opt/site/.eb-staged-rebuild example-3
#+end_src

#+begin_example
example-3  complete  backend=bwrap  modules=1/1
  published
  published  all/Example/1.0-GCCcore-15.2.0.lua  live=/opt/site/software/Example/1.0-GCCcore-15.2.0 retired=/opt/site/software/Example/.1.0-GCCcore-15.2.0.example-3
#+end_example

While the run was =failed=, the installation was the one from before it:

#+begin_src bash
/opt/site/software/Example/1.0-GCCcore-15.2.0/example-1.0.sh
#+end_src

#+begin_example
Example 1.0
#+end_example

=docs/examples/site.sh= in the repository runs these steps as its cases =fail= and =resume=.

** If it fails

| Message                                                                                   | Cause                                                                                                                  | What to do                                                                                                                      |
|-------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------|
| =eb-staged-rebuild: eb exited N; live modules were not changed=                           | The build failed again, with EasyBuild's status N.                                                                     | Correct what EasyBuild's output names, and resume again.                                                                        |
| =eb-staged-rebuild: verify failed; the live directory was not swapped. ...=               | The new tree fails the checks of =--verify=, and the run stays =built=.                                                | See [[file:verify-a-stage.org][Check a rebuild before it goes live]].                                                                                        |
| =eb-staged-rebuild: live software directory changed during the build; not published: REL= | Something other than this run changed the installation while the run was building; the run compares it with its start. | Find what changed it. A new run records the installation as it is now; =--skip-live-check= turns the comparison off.            |
| =eb-staged-rebuild: no journal at PATH=                                                   | No run of that name in that state root.                                                                                | Check the name with =status=, and the state root.                                                                               |
| =eb-staged-rebuild: run RUN_ID has an interrupted rollback; run rollback again=           | The machine stopped after a published tree was exchanged with its previous tree.                                       | Run =rollback= with the same state root and run id to complete the rollback.                                                     |
| =eb-staged-rebuild: run RUN_ID is rolling back to GEN; run rollback --to GEN to finish=   | A =rollback --to GEN= stopped part way, and the run is one it rolls back.                                              | Run =rollback --to GEN= again, as in [[file:roll-back.org][Put the previous installation back]].                                                        |
| =eb-staged-rebuild: run RUN_ID was rolled back; start a new run=                          | The run was rolled back, and a rolled-back run is not resumed.                                                         | Start a new run with another =--run-id=.                                                                                        |
| =eb-staged-rebuild: run RUN_ID is a retire record; rollback restores the module file=     | The name is a retire record's.                                                                                         | See [[file:retire.org][Retire a module file that another stack provides]].                                                                           |
| =eb-staged-rebuild: run RUN_ID is STATE but a module was already published=               | The journal contradicts itself, as no run of this program leaves it.                                                   | Compare =status= with the trees and module files it names, and restore them by hand; the journal is =runs/RUN_ID/journal.json=. |
| =eb-staged-rebuild: journal module plan does not record rel, prepared and new_hash=       | The publication plan is incomplete.                                                                                   | Restore the journal from a known-good copy or roll back the staged tree by hand.                                                                      |
| =eb-staged-rebuild: journal run id does not match its directory=                          | The journal in =runs/RUN_ID= names another run, or none; it was copied or edited there.                                | Put the journal back in its own run's directory, or restore it from a known-good copy.                                          |
| =eb-staged-rebuild: journal does not record FIELD=                                        | The journal lacks a field the command reads, or holds it as something other than text.                                 | Restore the journal from a known-good copy.                                                                                     |
| =eb-staged-rebuild: journal module plan does not record FIELD=                            | An entry of the journal's module plan lacks one of the paths the command reads.                                        | Restore the journal from a known-good copy or roll back the staged tree by hand.                                                |
| =eb-staged-rebuild: journal state root PATH is not STATE_ROOT=                            | The journal was written under another state root, PATH, and copied or edited into this one.                            | Give the command the state root the journal was written under, or restore the journal from a known-good copy.                   |

The journal's state root and the one given to the command are compared as
paths made absolute without following symbolic links: empty and =.=
segments are dropped, and each =..= removes the segment before it. POSIX
leaves the meaning of a path that begins with exactly two slashes to the
system, so =//opt/site/.eb-staged-rebuild= is kept as written and is not
the state root =/opt/site/.eb-staged-rebuild=; three or more leading
slashes count as one.
