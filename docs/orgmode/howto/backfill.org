* Record software installed before the ledger

Give the ledger a starting point for software that was installed before the site kept one, so that the history of each package starts with what was there.
Each observation becomes a =finding= record, stamped with the time it was made; nothing claims a build or an install.

** Before you start

- The eb-stack 0.7.0, the key, the log and the head of [[file:record-in-a-ledger.org][Record each rebuild in a signed ledger]].
- What you observed: for each installation its module name, its directory, and at least one piece of evidence, such as the EasyBuild log in its =easybuild/= directory.
- With the Python package, run =python3 -m eb_staged_rebuild.ledger_maintenance= where this guide runs =eb-staged-rebuild ledger-maintenance=.

** Steps

1. Write the manifest of the observations, here =~/backfill/audit-1.json=, and make it read-only:

   #+begin_src bash
   cat /home/alice/backfill/audit-1.json
   #+end_src

   #+begin_example
   {
     "schema": "eb-staged-rebuild/observed-backfill/1",
     "manifest_id": "audit-1",
     "observed_at": "2026-11-17T01:50:04Z",
     "observer": "alice",
     "stack": "2026.06",
     "target": "x86_64/amd/zen4",
     "observations": [
       {
         "module": "Example/1.0-GCCcore-15.2.0",
         "location": "/opt/site/software/Example/1.0-GCCcore-15.2.0",
         "modulefile": {"path": "/opt/site/modules/all/Example/1.0-GCCcore-15.2.0.lua", "sha256": "400e56c26dd10f9eb8b0e6b616582cc694614b6758dfddb9849268315e2b4761"},
         "provenance": [
           {"ref": "/opt/site/software/Example/1.0-GCCcore-15.2.0/easybuild/easybuild-Example-1.0-20261117.014923.log", "kind": "easybuild-log", "sha256": "d98f1972c6edb777ca7fe44215b8451abde0102f6d693a08e2c05f1643324408"}
         ],
         "note": "installed before the site kept a ledger"
       }
     ]
   }
   #+end_example

   =manifest_id= names this manifest for good; [[file:../reference/configuration.org][Configuration files]] lists every key.
2. Take its SHA-256, which pins the manifest to these bytes:

   #+begin_src bash
   sha256sum /home/alice/backfill/audit-1.json
   #+end_src

   #+begin_example
   14ad644d70787427c918edea2cea032e68250771c0acee3ce8cec017d6d5057e  /home/alice/backfill/audit-1.json
   #+end_example

3. Append the observations:

   #+begin_src bash
   eb-staged-rebuild ledger-maintenance backfill --eb-stack /opt/site/bin/eb-stack --log /opt/site/ledger/stack.jsonl \
     --public-key /opt/site/keys/ledger.pub --key /opt/site/keys/ledger.pem --head /opt/site/ledger-heads/head.json \
     --manifest /home/alice/backfill/audit-1.json --manifest-sha256 14ad644d70787427c918edea2cea032e68250771c0acee3ce8cec017d6d5057e
   #+end_src

   #+begin_example
   {"appended": 1, "manifest_id": "audit-1", "manifest_sha256": "14ad644d70787427c918edea2cea032e68250771c0acee3ce8cec017d6d5057e", "receipts": [{"event_id": "eb-staged-rebuild/backfill/audit-1/Example/1.0-GCCcore-15.2.0@0c775880ead71655", "head_root": "ea764f0ee8521861449a0dc14f6127489ce973e3dd1a284f919d685bd77221c1", "head_size": 1, "id": "eb5bed3da25dd944d264995d488de0126b9bd00c9b7785b37582c5be59e3f4d0", "index": 0, "replayed": false, "verified": true}], "replayed": 0}
   #+end_example

   =verified= says that =eb-stack ledger verify= found each record in the signed head the append wrote.

** Check that it worked

The ledger starts with the =finding=:

#+begin_src bash
/opt/site/bin/eb-stack ledger show --log /opt/site/ledger/stack.jsonl --package Example
#+end_src

#+begin_example
index	ts	action	target	module	actor
0	2026-11-17T01:50:04Z	finding	x86_64/amd/zen4	Example/1.0-GCCcore-15.2.0	alice
1 of 1 records
#+end_example

Running the same command again appends nothing: each observation is acknowledged as already recorded, and counted under =replayed=.
=docs/examples/site.sh= in the repository runs these steps as its case =backfill=.

** If it fails

| Message                                                                                                                      | Cause                                                                          | What to do                                                                               |
|------------------------------------------------------------------------------------------------------------------------------+--------------------------------------------------------------------------------+------------------------------------------------------------------------------------------|
| =ledger-maintenance: manifest PATH hashes to DIGEST, not the pinned DIGEST=                                                  | The manifest changed after you took its SHA-256, or the hash was mistyped.     | Take the hash again from the file you mean to append.                                    |
| =ledger-maintenance: manifest ID was backfilled from bytes hashing to DIGEST, not DIGEST; a backfill manifest is immutable=  | A manifest with this =manifest_id= and other content is in the ledger already. | Write the new observations into a manifest with a new =manifest_id=.                     |
| =ledger-maintenance: manifest observed_at TIME is after the current time TIME=                                               | The observation is dated in the future.                                        | Give the time the observation was made, in UTC.                                          |
| =ledger-maintenance: manifest stack 'NAME' is not the ledger's stack 'NAME'=                                                 | The ledger records another stack.                                              | Use the ledger of that stack, or the manifest's =stack= the ledger holds.                |
| =ledger-maintenance: eb-stack ledger append exited N: ...; nothing was acknowledged, retry the same command=, exit status 75 | eb-stack did not acknowledge a record.                                         | Fix the cause and run the same command; records already appended are not appended again. |
