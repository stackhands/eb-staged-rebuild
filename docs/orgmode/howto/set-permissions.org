* Set the permissions of a rebuild before it goes live

Give a rebuilt installation and its module file the ownership, modes or access-control lists the site wants, after the build and before the exchange, so that the installation is never live with other permissions.

** Before you start

- A rebuild that works without this, as in [[file:rebuild.org][Rebuild an installed module]].
- A program that sets the permissions, run as the account that runs the rebuild.
  It gets one argument, the path of a JSON file, =prepare-context.json=, that names each staged tree and each prepared module file; Files lists its keys.
  It must leave each tree complete and exit 0, and it must not move or remove anything.

** Steps

1. Write the program.
   The example site's, =docs/examples/site/prepare-publication= in the repository, lets every user read each staged tree and run its programs, and makes each module file readable by every user:

   #+begin_src python
   #!/usr/bin/env python3
   """The example site's --prepare program.

   eb-staged-rebuild runs it after the build and before the exchange, with the
   path of prepare-context.json. It lets every user read each staged tree and
   run its programs, and makes each module file readable by every user.
   """

   import json
   import os
   import subprocess
   import sys

   with open(sys.argv[1], encoding="utf-8") as handle:
       context = json.load(handle)
   for module in context["modules"]:
       subprocess.run(["chmod", "-R", "go+rX,go-w", module["staged"]], check=True)
       os.chmod(module["prepared"], 0o644)
       print(f"prepare-publication: {module['rel']}: go+rX,go-w on the tree, 0644 on the module file")
   #+end_src

   Install it where the account that rebuilds can run it, and others cannot change it:

   #+begin_src bash
   install -m 755 docs/examples/site/prepare-publication /opt/site/bin/prepare-publication
   #+end_src

2. Look at the permissions the installation has now, from the run before:

   #+begin_src bash
   ls -l /opt/site/software/Example/1.0-GCCcore-15.2.0/example-1.0.sh /opt/site/modules/all/Example/1.0-GCCcore-15.2.0.lua
   #+end_src

** If it fails

| Message                                                                                                      | Cause                                                               | What to do                                                                                                                                 |
|--------------------------------------------------------------------------------------------------------------+---------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------|
| =eb-staged-rebuild: --prepare must name a program; it is empty=                                              | =--prepare= was given an empty value.                               | Give it the program's path.                                                                                                                |
| =eb-staged-rebuild: publication preparation executable must be an absolute path=                             | The path given is relative.                                         | Give the absolute path.                                                                                                                    |
| =eb-staged-rebuild: publication preparation exited N; the live directory was not swapped=                    | The program exited with the status N, which is also the run's.      | Correct the program where it is, and =resume= the run, which runs it again before the exchange, as in [[file:recover.org][Finish a run that failed or stopped]]. |
| =eb-staged-rebuild: publication preparation left REL incomplete at PATH; the live directory was not swapped= | The program removed what marks the tree as a complete installation. | Correct the program, and start a new run.                                                                                                  |
