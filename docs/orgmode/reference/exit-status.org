* Exit status

The status each command exits with, and what it means for the state root and the live tree.

** eb-staged-rebuild

| Status | Command                     | Meaning                                                                                                                                                                                                                                                    |
|--------+-----------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|      0 | every command               | Done: the run published, the rollback put the old trees back or was done already, =resume= found the run complete, =gc= or =retire= ended, or a =--dry-run= printed its plan.                                                                              |
|      1 | =probe=                     | =--no-create= found that =--path= does not exist, or =--require-eb= did not find the =--eb= command after printing the probe report.                                                                                                                       |
|      1 | =resolve=                   | =MODULE_FILE= is not a regular file, or its =root= names no complete installation. The JSON is printed all the same.                                                                                                                                       |
|      1 | =verify=                    | The generation fails a check; =runs/RUN_ID/verify.json= lists the problems, and nothing was published.                                                                                                                                                     |
|      1 | every command               | The binary ran out of memory, and printed =eb-staged-rebuild: out of memory=; or the Python package stopped with a traceback, which is a bug.                                                                                                              |
|      2 | every command               | A usage error, with the usage on stderr; or a refusal or an operating-system error, with =eb-staged-rebuild: REASON= on stderr. A run refused before its build changed nothing; one refused later says in its journal how far it got.                      |
|      N | =run=, =resume=             | EasyBuild exited N during the build: the journal is =failed=, and nothing live changed. =128+N= is a build stopped by signal N, or a run that got =SIGTERM=, =SIGINT= or =SIGHUP= and stopped its build.                                                   |
|      N | =run=, =resume=             | The =--prepare= program exited N: the journal stays =built=, nothing live changed, and =resume= runs the program again.                                                                                                                                    |
|     75 | =run=, =resume=, =rollback= | A ledger record was not acknowledged, and the message says whether the directories were exchanged. It ends with the command that delivers the record once the ledger answers: =run resume= after =run= or =resume=, =run rollback again= after =rollback=. |

A run that the tree check or the live check stopped after the build exits 2, with its journal =failed=; one whose publication failed before a rename or an exchange landed exits 2, with its journal =built= and the old trees back.
A swap exchange or a fallback rename whose close or flush fails after it landed keeps the new names, saves the stop on every owning run's journal, and =resume= and =rollback= exit 2 and stop for intervention.
Publish, resume, =resume --verify= and =run --dry-run= judge the generation before any log, journal save, eb, or creation of the runs directory, on every backend. The judgment does not depend on the backend or on =bwrap_info.json=. A symlink above the generation is followed. Each existing child of the generation is checked without following a link. A symlink or a special file there is refused, and a regular file is left. =software= and =modules= must be directories. The run refuses a symlink, a fifo, a socket, or a regular file at each component under =software=. A dot-named regular file is left. The walk opens every dot-named directory, up to 32 components deep. A non-dot directory at version depth stays closed. =Core=, =Compiler=, and =MPI= stay open through the name directory. EasyBuild's install lock is left when it is a directory or a regular file directly under =software/.locks= and the name ends with =.lock=. The refusal exits 2. Every component that cannot be classified is refused. A real =modules= directory is opened one component at a time. A component of a recorded stage path, from the generation through the install directory, is refused when it is a symlink or a non-directory. A link inside any install is left. Resume of a complete run reports that the run is already complete before this judgment. A stage being rebuilt is removed without following links before eb. The judge keeps at most three directories open at a time and reports too many open files as a resource error. An absent path rebuilds only when its existing ancestors are real directories inside the generation.
A run with =--verify= whose generation fails the checks before publication exits 2 as well, with its journal =built= and nothing live changed; =resume= checks it again, and =--force= publishes it.
=status= says which.

Pre-build refusals that exit 2 before touching the live tree include:
- =--min-free-bytes= / =EB_STAGED_REBUILD_MIN_FREE_BYTES=: the generation filesystem has fewer available bytes than requested.
- =--require-exchange=: =renameat2(RENAME_EXCHANGE)= probe failed on the live filesystem.
- =--ledger-config=: =eb-staged-rebuild: ledger config KEY must be ...= (including non-finite or non-positive =timeout=).
