* Environment variables

The variables eb-staged-rebuild reads, and the environment of each program it starts.

** Read by eb-staged-rebuild

** What EasyBuild gets

Each EasyBuild command, the dry runs and the build alike, gets the caller's environment with these changes:

- =EASYBUILD_INSTALLPATH=, =EASYBUILD_PREFIX= and =EASYBUILD_REMOVE_GHOST_INSTALL_DIRS= are removed.
- When =--build-dir= is given to =run=, =EASYBUILD_BUILDPATH= is also removed so =--buildpath=DIR= takes effect; without =--build-dir=, =EASYBUILD_BUILDPATH= is left unchanged.
- =EASYBUILD_INSTALLPATH_SOFTWARE= and =EASYBUILD_INSTALLPATH_MODULES= name the generation's =software= and =modules= with the =installpath= and =userns= backends, and the live trees for the dry runs and for =bwrap=, where =--bwrap-installpath= moves the installation.
- The directory of the live tree's module files goes first on =MODULEPATH=, unless it is there already, so that a build into the generation finds the dependencies installed in the live tree.
  It is =all= under the directory =--modules= names, where EasyBuild writes them; the last =--suffix-modules-path= after =--=, or else =EASYBUILD_SUFFIX_MODULES_PATH=, gives EasyBuild another suffix than =all=, and an absolute one is the directory itself.
- The dry runs also get =EASYBUILD_OUTPUT_STYLE=basic=, which EasyBuild reads since 4.5.0.
  With rich, EasyBuild wraps its output at the console width and, once =FORCE_COLOR= is set and not empty, even to =0=, colours it through a pipe too, unless =TERM= is =dumb= or =unknown=.
  The build keeps the caller's output style; an =--output-style= after =--= reaches the dry runs and the build alike.

The =--prepare= program and =eb-stack= get the caller's environment unchanged.

** For tests

These make a command stop or fail on purpose, for the crash and fail tests; leave them unset.

| Variable                                                                                    | Effect                                                                                                                                                                                                                                            |
|---------------------------------------------------------------------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =EB_STAGED_REBUILD_PAUSE_AT=                                                                | Both builds pause before the step it names, or before every step that starts with what comes before a trailing =*=, after creating the file =EB_STAGED_REBUILD_PAUSE_READY= names, for =EB_STAGED_REBUILD_PAUSE_SECONDS= seconds, 30 when unset.  |
| =EB_STAGED_REBUILD_FAIL_AT=                                                                 | Each step of the list, separated by commas, fails with =[Errno 5] injected failure at STEP=. Only the =-Dtest-ops= test artifact and =tests/fail_cli.py=, which runs the Python package for the fail tests, read it; neither installed tool does. |
| =EB_STAGED_REBUILD_NOW=                                                                     | Only the =-Dtest-ops= test artifact and =tests/now_cli.py= read it. A number of seconds since the epoch, from 0 through 253402300799 (1970-01-01 00:00:00 UTC through 9999-12-31 23:59:59 UTC), replaces the wall clock for =run=, =resume= and =rollback=: the default run id and the journal, publication and ledger timestamps. =gc= keeps the wall clock. Unset or empty, or only ASCII space, leaves the wall clock. A value that is not a number is refused with =eb-staged-rebuild: EB_STAGED_REBUILD_NOW is not a number: 'VALUE'=; =nan= or =inf= with =eb-staged-rebuild: EB_STAGED_REBUILD_NOW is not a finite number: 'VALUE'=; a number outside that range with =eb-staged-rebuild: EB_STAGED_REBUILD_NOW is not a representable timestamp: 'VALUE'=. Each refusal is exit 2 and is printed before the command runs. Neither installed tool reads it. |
| =EB_STAGED_REBUILD_ACL_MODEL=, =EB_STAGED_REBUILD_ACL_STORE=, =EB_STAGED_REBUILD_ACL_FAULT= | Only the =-Dtest-ops= test artifact reads them: they emulate the ACLs of a filesystem.                                                                                                                                                            |
